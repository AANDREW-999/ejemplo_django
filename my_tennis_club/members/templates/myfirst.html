¿Qué es Django?

Django es un framework web open‑source para Python que facilita la creación de aplicaciones robustas en menos tiempo y con menos código. Sigue el patrón MVT (Model‑View‑Template), integra ORM, sistema de rutas, plantillas, seguridad y administración, todo listo para usar.

  • • Rápido por diseño
  • • Seguridad incorporada
  • • Escalable y modular
  • • Gran comunidad y ecosistema

Función de Django

Back‑end productivo

Provee ORM, migraciones, autenticación, sesiones, formularios y administración para construir APIs y sitios rápidamente.

Arquitectura limpia

Separa datos, lógica y presentación con MVT, favoreciendo pruebas, mantenibilidad y escalabilidad.

Estructura Django

manage.py
myproject/
	__init__.py
	settings.py
	urls.py
	wsgi.py
app/
	migrations/
	models.py   # Modelos (datos)
	views.py    # Vistas (lógica)
	urls.py     # Rutas
	templates/  # Plantillas (UI)
	static/     # Recursos estáticos
MVT en breve
  • Model: define y consulta datos con el ORM.
  • View: contiene la lógica que responde a la petición.
  • Template: renderiza HTML a partir del contexto.

Ventajas

Productividad

Estructura lista, admin automático y gran ecosistema de paquetes.

Seguridad

Protecciones contra XSS, CSRF, SQL Injection y gestión de contraseñas.

Escalabilidad

Caché, middlewares y soporte asíncrono con ASGI para alto tráfico.

Desventajas

  • Curva de aprendizaje inicial para entender su estructura.
  • Puede ser pesado para micro‑servicios muy pequeños.
  • El ORM puede limitar consultas SQL muy complejas (aunque permite SQL crudo).
