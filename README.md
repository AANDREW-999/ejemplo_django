## Acerca del proyecto
Pequeña guía rápida para levantar y explorar una página web con Django, usando buenas prácticas y un stack sencillo para aprender y prototipar.

## Inicio rápido
1) Crear y activar entorno virtual:
- Windows:
  - `py -m venv venv`
  - `venv\Scripts\activate`
2) Instalar dependencias mínimas:
- `pip install django`
3) Ejecutar el servidor de desarrollo:
- `python manage.py runserver`
4) Abrir en el navegador:
- http://127.0.0.1:8000/members/
